# Glossary

Each word in 8 words or fewer.

- **Repository (repo):** a project folder saved on GitHub.
- **Git:** saves snapshots of files, so we can undo.
- **Commit:** one saved snapshot, with a short note.
- **Git-ignored:** a file Git never saves or uploads.
- **GitHub Pages:** free website hosting from a GitHub repo.
- **noreply email:** a fake email that hides your real one.
- **uv:** a tool that installs Python tools.
